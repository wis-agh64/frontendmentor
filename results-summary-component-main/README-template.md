### What I learned

This was a simple enough challenge that it can be done pretty quickly even with vanilla CSS, so I took the chance
to try styling this time with Sass (I've only used Sass a long time ago and not very extensively). I got used to just using Bootstrap for webdev, but I wanted to refresh my responsive design skills, so I tried to mimic some Bootstrap-style classes using Sass and used flexbox quite *extensively*. No AI was used in the process. 

### Continued development
